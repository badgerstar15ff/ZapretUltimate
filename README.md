**Многофункциональный GUI для [zapret](https://github.com/bol-van/zapret)** — удобное окно
вместо ручного запуска `.bat`-файлов. Windows 10/11, интерфейс на русском языке.

## ❗ Это НЕ zapret

**ZapretUltimate — не сам zapret, а только дополнение к нему.** Это графическая оболочка:
она управляет уже установленным zapret, но не заменяет его и не содержит его внутри.

| | |
|---|---|
| Внутри программы есть zapret? | **Нет.** Ни `winws.exe`, ни драйвера WinDivert. |
| Работает без zapret? | **Нет.** Без него программа запустится, но подключиться не сможет. |
| Что нужно сделать? | **Указать папку с zapret** — вручную или скачать его из программы. |

**Как указать папку с zapret** — три способа:

1. **Автоматически** — программа сама ищет zapret в типичных местах (`D:\Program`,
   `C:\zapret`, папка рядом с программой, «Загрузки», «Рабочий стол»).
2. **Вручную** — «Полные настройки» → секция `ПРОГРАММЫ` → кнопка **«Выбрать папки»** →
   «Папка Zapret».
3. **Скачать** — «Полные настройки» → **«Скачать программы»** → Zapret
   (откроется официальный источник, оттуда скачивается и распаковывается вручную).

Если папка не указана и не найдена, при нажатии **«ПОДКЛЮЧИТЬ»** программа сама покажет окно
с двумя кнопками: **«Указать папку»** и **«Скачать Zapret»**.

## Что умеет

- **Подключение в один клик** — запускает выбранную стратегию zapret, показывает время работы
  и текущую нагрузку (CPU/RAM).
- **Автоподбор стратегии** — прогоняет пинг через каждую стратегию и предлагает лучшую;
  результат сохраняется, лучшая помечается в списке.
- **Режимы списков** — четыре варианта обработки трафика (разбор ниже).
- **Выбор путей** — отдельные кнопки для папки zapret, `.exe` TG WS Proxy и `.exe` клиента VPN.
  Путь, указанный вручную, имеет приоритет над автопоиском.
- **Загрузка программ** — панель со ссылками на официальные источники: Zapret, TG WS Proxy,
  Happ, v2RayTun, INCY.
- **Редактор списков** — правка `list-*.txt` прямо в окне программы, без блокнота.
- **Проверка списков** — многопоточная проверка доступности доменов из `lists`
  (результат: сколько OK, сколько FAIL).
- **Профили** — сохранённые наборы «стратегия + режим + DNS» с быстрым переключением.
- **DNS** — Cloudflare, Google, свой адрес или обратно на автоматический.
- **Переход на VPN** — запуск клиента VPN из программы, если обход не помогает.
- **Автозапуск** — через Планировщик заданий Windows, с правами администратора (без запроса UAC).
- **Трей и горячая клавиша** — сворачивается в трей, `Ctrl+Shift+Z` включает/выключает обход.
- **Темы и звуки** — тёмная/светлая тема, свои звуки интерфейса, простой и компактный режимы.
- **Проверка программ** — в один клик показывает, что установлено в системе: Zapret, VPN-клиенты,
  TG WS Proxy, списки.
  
## Установка

**Актуальная версия:** [v1.0.1](https://github.com/badgerstar15ff/ZapretUltimate/releases/latest)
· прямая ссылка на файл:
[ZapretUltimateSetup.exe](https://github.com/badgerstar15ff/ZapretUltimate/releases/download/v1.0.0/ZapretUltimateSetup.exe)

1. Скачай **`ZapretUltimateSetup.exe`** из раздела
   [Releases](https://github.com/badgerstar15ff/ZapretUltimate/releases) — и только оттуда.
2. Запусти установщик и согласись с запросом прав администратора —
   без них zapret не сможет поднять драйвер WinDivert.
3. Запусти **ZapretUltimate** (ярлык на рабочем столе или в меню «Пуск»).
4. Установи zapret отдельно и укажи папку с ним — либо скачай его из программы.

**Требования:** Windows 10/11 (x64), права администратора, установленный zapret.

> ⚠️ Не скачивай программу со сторонних сайтов и из «сборок» — неизвестно, что в них
> добавлено. Оригинальный установщик не требует отключения антивируса и не содержит
> рекламных модулей.

## Первый запуск

Программа запускается **с правами администратора** — это обязательное условие, а не баг.
Порядок действий:

1. Открой «Полные настройки» → `ПРОГРАММЫ` → **«Выбрать папки»** → укажи **папку Zapret**.
   Программа проверит, что в ней есть `general.bat` или `winws.exe`, и скажет, если это не она.
2. Вернись назад и выбери **стратегию** кнопкой «Сменить» (по умолчанию `general.bat`).
3. Нажми **«ПОДКЛЮЧИТЬ»**. Индикатор в шапке станет зелёным, пойдёт таймер.
4. Если сайты не открываются — нажми «Проверить пинг всех стратегий» и примени лучшую.

## Режимы списков

Открываются кнопкой **«Режим Zapret»**. От режима зависит, какой трафик идёт через zapret.

| Режим | Что происходит | Когда нужен |
|---|---|---|
| **Только выбранные сайты** | Обрабатываются домены из `lists\list-general.txt` (плюс твой `list-general-user.txt`) | Обычный режим. Минимум вмешательства, максимум скорости |
| **Все сайты, без списка** | Хост-лист не используется: обработке подлежит любой IP, исключений нет | Когда нужный сайт не попал в списки и лень их править |
| **Всё, кроме списка исключений** | Весь трафик, **кроме** доменов из `list-exclude.txt` | Обход для всего, а отдельные сайты (банки, госуслуги) идут напрямую |
| **Сайты .Ru** | Только российские домены из встроенного списка | Точечный сценарий |

**Как это работает внутри.** В режимах «Все сайты» и «Всё, кроме исключений» программа не правит
твой `list-general.txt`, а собирает отдельную команду запуска `winws.exe` со своими
hostlist-параметрами (для исключений используется `--hostlist-exclude`). Обычный `general.bat`
при этом не изменяется — твои файлы остаются целыми.

**Исключения** (для режима «Всё, кроме исключений») ведутся в отдельном окне: по одному домену
на строку.

## Профили

Профиль — это сохранённый набор настроек: **стратегия + режим списков + DNS**.
Удобно, когда для разных задач нужны разные наборы (например, «игры» и «работа»).

- **Сохранить:** «Полные настройки» → `ПРОФИЛИ И РЕЖИМЫ` → «Быстрые профили» → ввести имя →
  «Сохранить текущие настройки».
- **Загрузить:** там же, клик по названию профиля. Если обход был включён — он перезапустится
  с новыми настройками.
- **Удалить:** кнопка «Удалить» рядом с профилем.

## DNS

Переключение DNS-сервера для всех активных сетевых интерфейсов:

| Вариант | Серверы |
|---|---|
| Cloudflare | `1.1.1.1`, `1.0.0.1` |
| Google | `8.8.8.8`, `8.8.4.4` |
| Свой | любой IPv4-адрес (проверяется на корректность) |
| Авто (DHCP) | возврат к настройкам от провайдера |

**Важно:** смена DNS идёт через `netsh` и меняет системные настройки сети — это не «внутри
программы». Если после этого пропал интернет, верни режим **«Авто (DHCP)»**.

## Автозапуск

Три варианта в настройках:

- **Только открыть программу** — запускается при входе в Windows, но обход не включает.
- **Открыть и сразу подключить** — запускается и сразу поднимает обход.
- **Выключено.**

Реализовано через **Планировщик заданий** с флагом «наивысшие права» (`/RL HIGHEST`),
поэтому при входе не появляется запрос UAC. Запись в реестре создаётся дополнительно,
как запасной вариант.

## Горячие клавиши и трей

- Кнопка закрытия окна **сворачивает программу в трей**, а не завершает её.
- В трее: «Показать», «Подключить / Отключить Zapret», «Выход».
- Иконка трея меняет цвет: серая — выключено, зелёная — подключено.

## Настройки

Секции в «Полных настройках»:

| Секция | Что там |
|---|---|
| **ЗВУК И ТЕМА** | Переключатель звуков и смена темы |
| **ПРОФИЛИ И РЕЖИМЫ** | Простой режим, быстрые профили, компактный режим |
| **РЕЖИМ СПИСКОВ** | Выбор одного из четырёх режимов, настройка исключений |
| **ZAPRET** | Путь к zapret, открыть папку, открыть `lists` |
| **ПРОГРАММЫ** | «Выбрать папки» (zapret / TG WS Proxy / VPN) и «Скачать программы» |
| **DNS** | Cloudflare, Google, свой, авто |
| **АВТОЗАПУСК** | Три варианта запуска при входе в Windows |

## Если что-то не работает

**«Папка Zapret не найдена»**
: Укажи её кнопкой «Указать папку» или скачай zapret. В папке обязателен `general.bat`
  или `winws.exe` — иначе программа её не примет.

**Подключился, но сайты не открываются**
: Скорее всего, стратегия не подходит твоему провайдеру. Нажми «Сменить» → «Проверить пинг
  всех стратегий» → «Применить лучшую». Перебери несколько — у разных провайдеров работают разные.

**Не работают звуки**
: Проверь, что в настройках секция `ЗВУК И ТЕМА` показывает «Звуки: включены». Если да —
  посмотри громкость программы в «Микшере громкости» Windows: система запоминает отдельную
  громкость для каждого приложения, она могла оказаться на нуле.

**Сайт не открывается, хотя обход включён**
: Добавь домен в списки («Редактировать lists») или переключись на режим «Все сайты, без списка».

**Исключения не действуют**
: Они работают только в режиме «Всё, кроме списка исключений». В остальных режимах
  используется обычный список zapret.

**Программа не запускается с Windows после включения автозапуска**
: Проверь, что задача создана: «Планировщик заданий» → «Библиотека планировщика заданий» →
  `ZapretUltimate`. Если её нет — включи автозапуск заново, запустив программу
  от администратора.

**Вылетает при сохранении настроек**
: Настройки лежат в `zapret_gui_config.json` рядом с программой. Проверь, что файл не занят
  другой копией программы (закрой лишние) и что папка доступна для записи.

## Про антивирус

Windows Defender и SmartScreen **часто ругаются** на эту программу. Причины:

- запрос прав администратора при запуске;
- работа с драйвером WinDivert, который перехватывает сетевые пакеты;
- сборка без цифровой подписи (сертификат стоит денег, у проекта его нет).

Это **ложное срабатывание**, а не вирус. При предупреждении SmartScreen:
«Подробнее» → «Выполнить в любом случае».
